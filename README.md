
# How to Add and Customize Bubbles in the Blazor Maps Component

## Overview

This sample demonstrates how to create and customize bubble visualizations in the Syncfusion [Blazor Maps](https://www.syncfusion.com/blazor-components/blazor-map) component within a hosted Blazor WebAssembly application. The implementation shows how bubbles can be used to represent geographic data values on a map and how their appearance can be customized to improve data interpretation. The sample also demonstrates multiple bubble groups, different bubble types, and tooltip formatting techniques that help users explore geographic datasets through interactive visual representations.

**Examples**: https://blazor.syncfusion.com/demos/maps/bubble?theme=bootstrap5

**Documentation**: https://help.syncfusion.com/chart-sdk/blazor/maps/bubble


## Key Features

- Demonstrates bubble visualization using the Maps bubble rendering feature.
- Shows how bubble layers can represent geographic data values directly on a map.
- Demonstrates changing bubble types to alter visual presentation.
- Illustrates rendering multiple groups of bubbles within the same Maps component.
- Demonstrates bubble customization for better geographic data representation.
- Shows how tooltip functionality can be enabled for bubble elements.
- Demonstrates formatting tooltip content to present additional contextual information.
- Uses bubble-based visualization for displaying quantitative geographic data.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file:

   `AddingCustomBubbles.sln`

3. Restore NuGet packages.
4. Set the startup project
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root or startup project directory.

```bash
dotnet restore
dotnet run
```

## Project Structure

`Client/Pages/Index.razor` — Contains the primary Syncfusion Maps implementation, bubble rendering configuration, bubble customization settings, tooltip definitions, and geographic data visualization logic.
